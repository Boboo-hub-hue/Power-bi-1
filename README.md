# Financial Report 

##  Problem Statement
 GlobalMart is a fictional multinational retail company specializing in a variety of product categories, including Furniture, Office Supplies, and Technology. With operations spanning across multiple regions, GlobalMart strives to optimize its sales performance and profitability through data-driven decisions.
 
## Data Understanding 
1. Order ID: Unique identifier for each order
2. Order Date: Date the order was placed
3. Ship Date: Date the order was shipped
4. Region: Geographical region (e.g., East, West, Central, South)
5. State: State within the region
6. Category: Product category (e.g., Furniture, Office Supplies, Technology)
7. Sub-Category: Sub-category of the product (e.g., Chairs, Binders, Phones)
8. Product Name: Name of the product
9. Sales: Revenue generated from the sale
10. Quantity: Number of units sold
11. Discount: Discount applied (in percentage)
12. Profit: Profit earned from the sale
